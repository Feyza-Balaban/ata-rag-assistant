# Backend

The backend is jointly maintained by Feyza and Ümmü after the team task
redistribution.

It provides:

- `POST /ask` for source-grounded answers
- `GET /health` for readiness and indexed chunk count
- `GET /metrics` for basic usage analytics
- BM25 retrieval over `scraper/output/chunks.jsonl`
- confidence-based refusal for weak matches
- optional OpenAI Responses API generation
- local extractive fallback when no OpenAI key is configured

## Run locally

From the repository root:

```powershell
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app:app --reload --port 8000
```

Interactive API documentation is available at:

```text
http://127.0.0.1:8000/docs
```

## Environment variables

Copy `.env.example` values into your local environment. The minimum data
requirement is a valid `chunks.jsonl` generated by Ümmü's scraper.

`OPENAI_API_KEY` is optional. Without it, the API still runs in local
extractive mode so integration and error handling can be tested safely.
